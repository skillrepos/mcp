# Updated 2026-08-03 for MCP specification revision 2026-07-28.

# WHY THESE PINS
#   The 2026-07-28 revision is a breaking protocol change. Support for it landed
#   in MCP Python SDK v2.0.0 and, for FastMCP, in the 4.0 line. FastMCP 3.4.x
#   hard-pins mcp<2.0 and therefore cannot speak 2026-07-28 at all - it tops out
#   at 2025-11-25. So this course runs on FastMCP 4.
#
#   FastMCP 4.0.0b1 is a BETA. It is pinned exactly, on purpose: betas move.
#   Re-verify the labs before delivery if you bump it. `fastmcp` on PyPI is only
#   a metadata wrapper around `fastmcp-slim`, so the constraint below keeps the
#   two in lockstep (uv in particular needs the explicit pin).
#
#   REMOVED: langchain_mcp_adapters. It imports mcp.server.fastmcp, a module
#   deleted in SDK v2, so it cannot be installed alongside this stack.
#   Lab 1's agent now drives the tool-calling loop directly - see
#   extra/agent_mcp.txt. Track langchain-ai/langchain-mcp-adapters#578 if you
#   want it back later.
